# Property Utility Cost Tracker

## Project Overview
This project is an interactive property utility cost dashboard created to analyse and monitor utility expenditure across a portfolio of properties.

The dashboard tracks electricity, gas, water and council tax costs and provides a clear overview of portfolio spending using KPIs, pivot tables, charts and an interactive property slicer.

## Dashboard Features
- Total portfolio cost
- Average property cost
- Highest property cost
- Lowest property cost
- Total utility cost by property
- Utility cost breakdown by property
- Total cost by utility type
- Interactive property slicer for filtering the dashboard

## Key Insights
- Total portfolio utility cost: £1,952
- Average cost per property: £390.40
- Highest property cost: £495
- Lowest property cost: £303
- Council Tax represents the largest utility-related cost category across the portfolio.
